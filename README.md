# کتابخانه نور | Noor Islamic Library

اپلیکیشن اندروید آفلاین برای مطالعه **قرآن کریم، مفاتیح الجنان، صحیفه سجادیه و نهج‌البلاغه** با متن عربی، ترجمه فارسی، جستجو، نشانک و یادداشت.

> قانون پروژه: هیچ متن عربی یا ترجمه‌ای با هوش مصنوعی تولید یا تکمیل نمی‌شود. هر کتابی که متن معتبرش در دسترس نباشد، در برنامه «ناقص» یا «افزوده نشده» نمایش داده می‌شود.

## وضعیت محتوا

| کتاب | وضعیت | منبع |
|---|---|---|
| قرآن کریم | خودکار در هر Build از Tanzil دانلود و با ۱۱۴ سوره / ۶۲۳۶ آیه کنترل می‌شود | Tanzil Project + ترجمه مکارم شیرازی |
| مفاتیح الجنان | **منتخب مفاتیح الجنان** (چاپ برهان، ۳۸۴ صفحه، نسخه قائمیه). صفحات PDF دقیقاً مثل کتاب نمایش داده می‌شوند؛ متن فقط برای فهرست و جستجو استفاده می‌شود | `content/sources/mafatih.pdf` |
| صحیفه سجادیه | نیازمند فایل منبع معتبر | `content/sources/sahifa.json` |
| نهج‌البلاغه | نیازمند فایل منبع معتبر | `content/sources/nahj.json` |

قالب فایل‌های منبع: [docs/CONTENT-FORMAT.md](docs/CONTENT-FORMAT.md). وضعیت دقیق هر Build در گزارش `QC-REPORT.md` (بخش Summary اجرای Actions و Artifact با نام `content-qc-report`) آمده است.

## دریافت APK (بدون نیاز به برنامه‌نویسی)

1. در همین مخزن به تب **Actions** بروید.
2. آخرین اجرای **Build APK** (تیک سبز) را باز کنید.
3. پایین صفحه در بخش **Artifacts** فایل `Noor-Islamic-Library-debug` را دانلود کنید.
4. ZIP را باز کنید؛ داخل آن `Noor-Islamic-Library.apk` است. آن را روی گوشی نصب کنید (اجازه «نصب از منبع ناشناس» لازم است).

برای ساخت دوباره: Actions › Build APK › **Run workflow**.

## نسخه Release امضاشده

در Settings › Secrets and variables › Actions چهار Secret بسازید: `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`. سپس Run workflow را با گزینه `release` اجرا کنید.

## امکانات فعلی

- صفحه اصلی با چهار کتاب، ادامه مطالعه، آخرین مطالب، هدف روزانه، متن منتخب روز
- Reader: اندازه/فونت/فاصله خطوط، نمایش یا پنهان‌کردن ترجمه، حالت شب/روز/کرم، کپی و اشتراک با ذکر منبع
- جستجو در عربی و فارسی در همه کتاب‌ها (یکسان‌سازی ی/ي و ک/ك، نادیده‌گرفتن حرکات)
- نشانک با پوشه، یادداشت شخصی، تاریخچه، ذخیره خودکار آخرین موقعیت
- پیمایش خودکار (دکمه ⇈ در بالای Reader) با سرعت قابل تنظیم، در قرآن و مفاتیح
- دکمه خروج در صفحه اصلی
- پخش تلاوت قرآن آیه‌به‌آیه (۵ قاری، سرعت پخش، پخش پس‌زمینه و کنترل از اعلان، دانلود سوره برای آفلاین؛ منبع: EveryAyah.com)
- پشتیبان‌گیری و بازیابی نشانک‌ها و یادداشت‌ها، یادآور روزانه
- به‌روزرسانی محتوا بدون حذف نشانک‌ها و یادداشت‌ها

## هنوز انجام نشده

- حالت آفلاین کامل صوت برای همه سوره‌ها در یک مرحله (فعلاً دانلود سوره‌به‌سوره)
- نمایش تفسیر
- تصاویر محیط برنامه (نیازمند اجرا روی دستگاه/شبیه‌ساز)

## ساخت نسخه‌های بعدی

هر Push یک Build جدید می‌سازد. شماره نسخه از شماره اجرای Actions گرفته می‌شود. ساختار: `app/src/main/java/com/noor/library/{data,presentation,util}` (لایه‌های داده، دامنه/مخزن و رابط کاربری).

## ساخت دوباره‌ی داده‌های مفاتیح

`python3 scripts/extract_mafatih.py content/sources/mafatih.pdf content/sources/mafatih.json` (نیازمند `pdftotext`).
لایه متنی این PDF حرکات عربی را از حروف جدا ذخیره کرده است؛ به همین دلیل متن دوباره‌چینی نمی‌شود (تحریف اعراب) و صفحات اصلی نمایش داده می‌شوند.
