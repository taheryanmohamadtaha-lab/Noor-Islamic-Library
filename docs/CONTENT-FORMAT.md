# قالب فایل‌های محتوا

برای افزودن مفاتیح الجنان، صحیفه سجادیه یا نهج‌البلاغه، یک فایل JSON با نام `content/sources/<mafatih|sahifa|nahj>.json` بسازید. Build فقط در صورتی آن را می‌پذیرد که منبع، مترجم، نسخه و مجوز مشخص باشد.

```json
{
  "source": "نام ناشر/نسخه مرجع متن عربی",
  "translator": "نام مترجم",
  "version": "نسخه یا سال چاپ",
  "license": "مجوز بازنشر",
  "complete": true,
  "sections": [
    {
      "type": "dua",
      "number": 1,
      "title": "عنوان بخش",
      "passages": [
        { "n": 1, "ar": "متن عربی", "fa": "ترجمه فارسی", "ref": "شماره/مأخذ" }
      ]
    }
  ]
}
```

نوع بخش (`type`): `dua`، `ziyarat`، `amal` (مفاتیح و صحیفه)، `khutba`، `letter`، `hikma` (نهج‌البلاغه).

کنترل کیفیت:
- صحیفه: ۵۴ بخش از نوع `dua`.
- نهج‌البلاغه: ۲۴۱ خطبه، ۷۹ نامه، ۴۸۰ حکمت (شماره‌گذاری نسخه صبحی صالح). برای نسخه دیگر عددها در `scripts/build_content.py` (`EXPECTED`) تغییر کنند.
- مفاتیح: وضعیت «کامل» فقط وقتی `"complete": true` باشد.
- هر فراز بدون متن عربی یا بدون ترجمه، کتاب را «ناقص» می‌کند.
